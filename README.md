AI Agent Loop Demo

Overview

This project demonstrates the basic working of an AI agent using a Jupyter Notebook. It explores how a language model can interact with external tools, retrieve relevant information, and use the results to generate answers.

Features

LLM Integration: Uses the Gemini API to interact with a language model.

Document Search: Implements a search_documents() function to retrieve relevant information from a sample document collection.

Tool Calling: Demonstrates how an AI model can request and use an external tool.

Agent Loop: Shows the interaction between the model, available tools, and tool results until a final response is generated.

Follow-up Questions: Tests the agent's ability to answer questions using retrieved information.

Technologies Used

Python

Jupyter Notebook

Google Gemini API
